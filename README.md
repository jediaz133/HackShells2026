# Project PAIDA, Puffles Artificial Intelligence Diet Assistant

**Main purpose:** To quickly and easily track calories eaten, burned, and weight using an AI assistant that will calculate calories burned and eaten based on your info.

**Inspiration:** I've found myself asking Gemini a lot how many calories my meal was and how much calories I would burn in a day. With this I can save and automatically track everything I eat and how many calories I burn. 

**Why not use a diet app?:** I've personally found them to be intimidating and I don't know where the data is going. Those diet apps also store data on you and this keeps everything local if you want (exception is this example uses Gemini with langchain however it takes one line to swap to an ollama mode)
